# Blinkit Sales Analysis Dashboard

## Project Overview
Analyzed 8000+ Blinkit grocery sales records containing 16 item categories and 4 outlet types to identify sales trends, outlet performance, and customer insights.

## Tools Used
- Python
- SQL
- Power BI
- Power Query

## Key Analysis
- Sales Performance Analysis
- Outlet Type Comparison
- Item Category Insights
- Rating & Item Visibility Analysis
- KPI Dashboard Creation

## Features
- Interactive Power BI Dashboard
- Dynamic Filters & Slicers
- KPI Cards & Charts
- Data Cleaning & Transformation

## Key Insights
- Identified top-performing outlet types
- Analyzed high-revenue product categories
- Compared sales across outlet locations
- Generated actionable business insights
